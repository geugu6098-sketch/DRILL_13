# DRILL13

LEC15 game framework exercise with a selectable ball item mode.

## Run

Install the `pico2d` and `transitions` dependencies, then run:

```powershell
python main.py
```

## Controls

- Left/Right arrows: move
- Q: open or close item mode; the game world is paused while it is open
- 0: select no ball
- 1: select the 21x21 ball
- 2: select the 41x41 ball
- E: fire the selected ball in the direction the character faces
- P: open the regular pause screen
- Escape: return to the title screen from play or pause
